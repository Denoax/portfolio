# Minimal numerical loader v3

Mani rejected the compilation loader. This replaces that direction completely:
black viewport, one large white three-digit number at the lower left, and a
2px bottom progress bar. No normal-screen captions, sound, terminal or gate.

Source: https://lusion.co/ and the supplied v3 reference/patch. Its lower-left
numeral composition is adapted in original DOM/CSS with system sans-serif;
no creator font, media or private code is copied. The bar is Mani's addition.
The supplied inspection observed 000 only; full reference counting/exit was not
observed. Local capture also shows 000; it does not establish Lusion internals.

BootSession remains the readiness owner. Number and bar show completed required
preparation milestones; only the actual target draw permits 100. Interpolation
is presentation, never an artificial minimum. Existing failure recovery,
input/focus, native fallback and reveal remain. Saved/OS Less motion avoids
interpolated progress. The v2 theme repair and all portfolio scenes are retained.

Validation: production build/typecheck, loading-progress/boot-state/first-paint
checks and native cold/warm, delayed preparation, saved dark, portrait/reduced
motion and recovery review. The known graphics initialization pause is not
claimed fixed. Human visual, physical-device and Safari acceptance remain open.
No production deployment is included; the candidate goes to a guarded testing
branch. Review delivery contains the scoped patch/source and a short unedited
startup, rather than the previous media/trace archive.
