## Readiness and ownership

Vite projects the real catalogue into persistent inline HTML/CSS. The lightweight
bootstrap observes an actual first-contentful paint and yields a browser task
before importing the main app. `BootSession` owns SHELL, PREPARING, PRIMED,
REVEALING, COMPLETE and honest FALLBACK states with generation-bound callbacks.

Preparation resolves actual explicit UI/atlas/cue fonts, requested display faces
and layout, atlas/poster decode/upload, owned foreground/trail shader preparation,
the stable optional Waves outcome, and a complete base/trail/glass target draw.
The same scene/renderer survives the cover dissolve. Temporary root inertness
blocks input while still permitting the existing glass renderer to prepare.
Native font readiness follows the [CSS Font Loading specification](https://www.w3.org/TR/css-font-loading-3/#font-face-set-ready).

Opening active time stays at zero during preparation. Formation begins in the
last third of the cover dissolve; input remains blocked until COMPLETE. Focus
follows the React input-fence commit. Audio/media playback are not readiness
prerequisites. The 12s total-navigation deadline is a failure boundary, with
native project content or working reload/GitHub/contact links. A failed font
uses stable platform text. Retired image decodes cannot mutate a new owner;
retiring R3F frames cannot overwrite recovered native layout.

- Build includes TypeScript checking. New production boot-owner checks cover
  prerequisites, stale generations, optional failure and exactly-once completion.
- Actual inline bootstrap plus actual settings validator: 48 cases, including
  v1/v2/invalid/corrupt/denied storage. The same regression fails old baseline.
- Twenty-five matched real wave/ring captures cover multiple phases, light/dark
  and intermediate themes, brightness80/100/140, DPR1/2 and desktop/portrait.
  Glyph pixel and geometry-attribute hashes remain identical. Pixel statistics
  are sampled rendered luminance, separate from palette endpoint calculations.
- Measured native terminal landmarks, history bound/retirement/disposal,
  portrait and reduced motion pass. Reference and startup recordings were
  played at1x muted; full/detail frames were inspected. This is not continuous
  human motion or listening approval.
- Nineteen native production boot scenarios pass: delayed import and input
  fencing; delayed fonts/posters and real display font; failed entry/bootstrap,
  required font/shader/display font/WebGL/deadline; optional Waves shader;
  context loss; direct Worlds/documents; reduced portrait touch; freeze/return;
  Back navigation. Synthetic GL/API faults are labeled separately from actual
  delayed/failed network requests. Browser errors in failure fixtures are expected
  evidence; normal runs have none.
- Existing transport20, section7 and wave preparation contracts pass. Native
  signed momentum, hold/release, keyboard, quiet theme, smoke/pigment/leave/return,
  OS/saved less-motion, eleven-project actions, panes/sliders and Pelagic pass.
  Those preservation checks ran at `89fd135`; the sole later runtime change
  strengthens requested-font readiness. The full boot suite and startup captures
  were repeated at final `0401b14`.
- Source comparisons preserve `src/content`, real public assets, dependency
  manifests/lockfile, smoke field and intro transport/projection equations.

Full cold/warm startup traces, filmstrips, unedited recordings and distributions
