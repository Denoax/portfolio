# Terminal index reference study

Original visual reference: Jean Dawson, Pixel Bath website (2020). Design by Mouthwash; interactive development by Guillaume Colombel. Creator case study: https://guillaumecolombel.fr/projects/jean-dawson . The supplied recording is private study evidence, never a runtime asset or soundtrack.

Supporting mechanism study: Manoela Ilic / Codrops, Hover Animations for Terminal-like Typography: https://tympanus.net/codrops/2024/06/19/hover-animations-for-terminal-like-typography/ . MIT source study: https://github.com/codrops/LineTextHoverAnimations at 00fdd50a5daa48a9fcb400d19d17b1dac5935e68.

This portfolio uses original semantic markup, CSS and a bounded per-row inverse-text history. No demo runtime libraries, random glyph substitutions, creator media, fonts or soundtrack are copied. Text is a build-time projection of Mani's real catalogue. A stable platform monospace face is used throughout a boot; exact original reference font is unverified. The derivative study's MIT notice is retained alongside this record.
